CoCompose 0.1.0 / Windows x64

1. ZIP을 폴더에 모두 압축 해제합니다.
2. CoCompose.exe를 더블클릭합니다. PowerShell이나 Python은 앱 실행에 필요 없습니다.
3. Play로 재생하고 Audio Settings에서 출력 장치를 선택합니다.

프로젝트는 Windows 문서 폴더의 CoCompose에 저장됩니다.
앱의 프로젝트 폴더 버튼으로 실제 저장 위치를 열 수 있습니다.
업데이트할 때 앱을 종료하고 새 ZIP을 별도 폴더에 풀어 실행하세요.
프로젝트 데이터는 배포 폴더 밖에 있으므로 유지됩니다.

외부 AI 연동: state.json을 읽고 변경한 전체 상태를 project.json에 씁니다.
실행 중인 앱에 반영되며 프로젝트를 다시 열 필요가 없습니다.
tools/cocompose.py는 선택적 Python 도구이며 앱 실행에는 필요 없습니다.

실행/빌드 가이드와 소스:
https://github.com/YunSeojoon/tracktion_engine/tree/ai-editor
docs/windows-guide.ko.md

현재 빌드는 코드 서명이 없습니다. 설치 프로그램/자동 업데이트는 포함하지 않습니다.
타사 VST3별 호환성과 청음 검증은 별도로 필요합니다.
오픈소스 고지는 licenses 폴더와 해당 소스 저장소를 참고하세요.
